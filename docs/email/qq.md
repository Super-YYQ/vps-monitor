# QQ 邮箱配置指南

[返回邮件配置](README.md) · [返回项目首页](../../README.md)

适用于普通个人 QQ 邮箱（`@qq.com`）。腾讯企业邮箱使用不同服务地址，不直接套用本页。

## 1. 获取邮箱授权码

1. 登录 [QQ 邮箱网页版](https://mail.qq.com/)。
2. 打开“设置”，找到“IMAP/SMTP 服务”或“POP3/SMTP 服务”。界面版本不同，入口可能在“常规”“账户”或相关第三方服务设置中。
3. 开启包含 SMTP 的服务，并按页面提示完成手机验证。
4. 点击“生成授权码”或使用开启服务后提供的授权码，为本工具保留一份凭据。

这里使用邮箱授权码，不使用 QQ 日常登录密码。腾讯的 [Email 连接器官方说明](https://cloud.tencent.com/document/product/1270/55456) 也明确要求 QQ 邮箱使用授权码；可查看 [QQ 邮箱授权码帮助](https://service.mail.qq.com/cgi-bin/help?subtype=1&id=28&no=1001256)。设置入口示例见 [华为云的 QQ 邮箱接入说明](https://support.huaweicloud.com/usermanual-roma/roma_03_5025.html)。

## 2. 填入 VPS Radar

在“通知与设置 → 邮件通知”逐项填写：

| 面板字段           | 填写内容                                             |
| ------------------ | ---------------------------------------------------- |
| 启用 SMTP 邮件通知 | 勾选                                                 |
| SMTP 服务器        | `smtp.qq.com`                                        |
| 端口               | `465`                                                |
| 加密方式           | **SSL / TLS（通常 465）**                            |
| 登录账号           | 你自己的完整 QQ 邮箱地址，如“你的 QQ 号@qq.com”      |
| 密码 / 邮箱授权码  | 上一步取得的授权码                                   |
| 发件人邮箱         | 与登录账号完全相同                                   |
| 接收邮箱           | 接收提醒的完整邮箱地址，每行一个；可以和发件邮箱相同 |

SMTP 主机及 SSL 465 参数参照 [腾讯云 SMTP 配置表](https://intl.cloud.tencent.com/zh/document/product/1266/71700)。本例固定使用 465 + SSL，避免混用端口和加密方式。

## 3. 发送测试邮件

1. 点击“保存设置”。
2. 点击“发送测试邮件”。
3. 到“通知记录”查看“已发送”，并检查收件箱是否出现 `[VPS Radar] 邮件通知测试`。
4. 返回所选机型，确认“补货时发送邮件”已勾选；如果首次检查有货也希望提醒，再打开“首次确认有货也通知”。

测试邮件会真实发送。记录为“已发送”表示 SMTP 接受，仍需检查是否进了垃圾邮件。

## 4. 常见错误

- **认证失败**：检查是否填了日常密码而非授权码、QQ 号码后是否漏了 `@qq.com`、授权码是否被撤销、SMTP 是否还开启。
- **发送人被拒绝**：将发件人改为登录账号相同的邮箱，先不要使用自定义显示名或未核实的别名。
- **超时**：从运行 VPS Radar 的服务器检查 `smtp.qq.com:465` 出站连接，而不是只测试自己电脑。
- **更换授权码后仍失败**：把新授权码粘贴到密码框并点击保存；留空只会保留旧值。
- **不再需要这台服务器发信**：在 QQ 邮箱的授权码 / 第三方服务管理中撤销对应授权，面板也关闭邮件通知。
