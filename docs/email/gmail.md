# Gmail 配置指南

[返回邮件配置](README.md) · [返回项目首页](../../README.md)

本项目目前采用 SMTP 用户名与密码认证，不提供“使用 Google 登录”或 OAuth 授权。因此 Gmail 接入使用 **Google 应用专用密码（App Password）**，且需要账号允许创建它。

## 1. 开启两步验证

登录 [Google 账号安全页面](https://myaccount.google.com/security)，开启“两步验证（2-Step Verification）”。Google 要求先开启两步验证才能创建应用专用密码。[Google 官方说明](https://support.google.com/mail/answer/185833?hl=zh-Hans)

## 2. 创建应用专用密码

1. 打开 [应用专用密码管理](https://myaccount.google.com/apppasswords)，必要时重新登录。
2. 为应用填写便于识别的名称，例如 `VPS Radar`。
3. 创建并复制生成的 16 位应用专用密码，填入面板的“密码 / 邮箱授权码”。复制时不要额外加入展示用的空格或换行。

如果已经开启两步验证，仍看不到此入口，可能是工作 / 学校账号的策略限制、账号开启高级保护，或两步验证仅使用安全密钥。此时本工具不能代替管理员解除限制；使用允许应用专用密码的发信账户，或另选 QQ / 163。更改 Google 账号主密码后，原有应用专用密码会被撤销，需要重新生成。[Google 官方说明](https://support.google.com/mail/answer/185833?hl=zh-Hans)

## 3. 填入 VPS Radar

| 面板字段           | 填写内容                         |
| ------------------ | -------------------------------- |
| 启用 SMTP 邮件通知 | 勾选                             |
| SMTP 服务器        | `smtp.gmail.com`                 |
| 端口               | `465`                            |
| 加密方式           | **SSL / TLS（通常 465）**        |
| 登录账号           | 你的完整 Gmail 邮箱地址          |
| 密码 / 邮箱授权码  | 为 VPS Radar 创建的应用专用密码  |
| 发件人邮箱         | 与登录账号一致                   |
| 接收邮箱           | 接收补货提醒的完整地址，每行一个 |

也可将端口与加密方式一起改为 **587 + STARTTLS**。不要将 SSL 465 与 STARTTLS 587 交叉混填。Google 官方列出的 Gmail SMTP 主机是 `smtp.gmail.com`，SSL 使用 465，TLS 使用 587。[Google SMTP 配置说明](https://support.google.com/a/answer/176600?hl=en)

Google Workspace 用户应使用完整组织邮箱，且需管理员允许该认证方式。此处不使用 `smtp-relay.gmail.com`，后者属于不同的管理员中继配置。

## 4. 保存并测试

点击“保存设置”，再点击“发送测试邮件”，到“通知记录”查看结果。检查收件箱及垃圾邮件；邮件标题为 `[VPS Radar] 邮件通知测试`。

发信连接由部署服务器建立。服务器需要能够解析并访问 `smtp.gmail.com` 对应的 SMTP 端口。你在电脑或浏览器中能打开 Gmail，不代表服务器具备同样的连接条件。

## 5. 常见错误

| 现象                         | 处理办法                                                                           |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| `535` / SMTP 认证失败        | 核对完整邮箱和应用专用密码；检查是否用主账号密码、凭据已被撤销或账户策略禁止该方式 |
| 提示需要应用专用密码         | 开启两步验证并生成应用专用密码，保存后重新测试                                     |
| 没有应用专用密码入口         | 按第 2 节确认账号限制，不尝试恢复已淘汰的“低安全性应用”登录方式                    |
| 连接超时                     | 检查服务器出站连接、DNS、防火墙和提供商端口限制                                    |
| 显示已发送但没收到           | 检查收件人地址、垃圾邮件与过滤规则；SMTP 接受不等于主收件箱已显示                  |
| 改了 Google 主密码后停止发信 | 重新创建应用专用密码并更新面板                                                     |

更多错误码可查 [Gmail 官方 SMTP 错误说明](https://support.google.com/mail/answer/3726730?hl=en)。本项目为防止泄露信息，会将部分服务端错误归纳为简短中文说明，不直接展示完整 SMTP 回复。
