# 网易 163 邮箱配置指南

[返回邮件配置](README.md) · [返回项目首页](../../README.md)

适用于普通个人 `@163.com` 邮箱。126、VIP 和网易企业邮箱可能使用不同服务器，请勿只修改邮箱地址后直接套用。

## 1. 开启服务并获取授权码

1. 登录 [网易 163 邮箱网页版](https://mail.163.com/)。
2. 打开“设置 → POP3/SMTP/IMAP”。
3. 找到“IMAP/SMTP 服务”并开启；如果界面显示其他包含 SMTP 的服务入口，以当前页面说明为准。
4. 根据提示完成账号安全验证，获取客户端授权码。已经开启服务时，可在该页面的授权码管理中生成新的凭据。

这份凭据用于第三方客户端发信，不填写日常网页登录密码。步骤可参照 [华为云官方 163 邮箱接入说明](https://support.huaweicloud.com/usermanual-roma/roma_03_5051.html)；腾讯的 [Email 接入文档](https://cloud.tencent.com/document/product/1270/55456) 同样说明 163 邮箱应使用授权码。

## 2. 填入 VPS Radar

| 面板字段           | 填写内容                         |
| ------------------ | -------------------------------- |
| 选用此配置时启用通知 | 勾选                             |
| SMTP 服务器        | `smtp.163.com`                   |
| 端口               | `465`                            |
| 加密方式           | **SSL / TLS（通常 465）**        |
| 登录账号           | 你的完整 `@163.com` 邮箱地址     |
| 密码 / 邮箱授权码  | 刚刚取得的网易客户端授权码       |
| 发件人邮箱         | 与登录账号一致                   |
| 接收邮箱           | 接收提醒的完整邮箱地址，每行一个 |

本指南采用 `smtp.163.com:465` + SSL，参数见 [腾讯云 SMTP 配置表](https://intl.cloud.tencent.com/zh/document/product/1266/71700)。不要仅因为面板默认显示 587，就保留它不改。

## 3. 保存与测试

1. 点击“保存配置”，将该配置设为当前，再点击“发送测试邮件”。
2. 到“通知记录”确认投递结果。
3. 检查收件箱和垃圾邮件中的 `[VPS Radar] 邮件通知测试`。
4. 为想监控的机型开启“启用监控”和“补货时发送邮件”；首次有货也要提醒时，再开启对应选项。

接收邮箱可以同样是这个 163 邮箱，也可以是 QQ 或 Gmail。只有发信账户需要提供授权码。

## 4. 常见错误

- **认证失败**：检查 SMTP 是否开启、是否使用授权码、账号是否填写完整 `@163.com` 地址。
- **曾经成功，后来失败**：确认授权码是否失效、被撤销或账户触发安全验证；重新生成后在面板保存新值。
- **邮件服务器拒绝发件人**：先保持发件人邮箱与登录账号完全一致。
- **超时或 TLS 失败**：确认使用端口 465 + SSL，并从程序所在服务器检查 `smtp.163.com:465` 连接。
- **已发送但没收到**：检查收件人拼写、垃圾邮件、收信过滤规则；不要连续点击测试按钮。

统一的通知状态、重试逻辑和排错方法见 [邮件总说明](README.md)。
